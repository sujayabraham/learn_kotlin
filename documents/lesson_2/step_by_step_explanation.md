# Step-by-Step Explanation: Kotlin Tour Basics

This document details the implementation of introductory Kotlin concepts from the official Kotlin Tour.

## 1. Defining the Logic in Kotlin

We created a new file [KotlinTour.kt](file:///Users/sujay/learn_kotlin/app/src/main/java/learn_kotlin/KotlinTour.kt) to encapsulate the tour's examples into callable functions.

### Variables: `val` vs `var`
- `val` (Value): Immutable reference. Once assigned, it cannot change.
- `var` (Variable): Mutable reference. Can be reassigned.
- **Example**: `popcorn` was declared with `val`, while `customers` used `var` to allow updates.

### String Templates
- Used `$` to inject variable values: `"$customers"`.
- Used `${}` for expressions: `"${customers + 1}"`.

### Functions
- Declared with the `fun` keyword.
- Parameters follow the `name: Type` format.

## 2. Accessing from Java

Since these are top-level functions in `KotlinTour.kt`, Kotlin generates a Java-compatible class called `KotlinTourKt`.

In [App.java](file:///Users/sujay/learn_kotlin/app/src/main/java/learn_kotlin/App.java), we added:
```java
KotlinTourKt.showHelloWorld();
KotlinTourKt.demonstrateVariables();
KotlinTourKt.demonstrateStringTemplates();
KotlinTourKt.introducePerson("Mary", 20);
```

The project was compiled using `./gradlew :app:assemble`. The Java compiler successfully found the `KotlinTourKt` class generated by the Kotlin compiler.
